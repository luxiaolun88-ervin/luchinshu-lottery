演算法說明（任何人都能重算）

  1. 名單整理：每行一個帳號，去除前後空白與開頭的「@」，做 Unicode NFC 正規化並轉小寫作為比對鍵；相同比對鍵只保留一筆（顯示第一次出現的原始寫法）。
  2. 標準名單（canonical list）：比對鍵依 Unicode 碼位排序，以「\n」串接、UTF-8 編碼，計算 SHA-256 → 名單雜湊。抽獎前先公布此雜湊，之後名單無法偷改。
  3. 種子（seed）：抽獎前預告、當時尚未產生的公開數字，例如某期台灣彩券開獎號碼或某個未來比特幣區塊雜湊。
  4. 每位參加者分數 = SHA-256( seed + "|" + 平台 + "|" + 比對鍵 )，平台為 FB 或 IG；合併抽時平台為 ALL（同平台內去重，跨平台同名各算一筆；抽獎前人工確認為同一人者合併為單一項目「FB:x+IG:y」），比對鍵改為加上平台前綴的「FB:帳號」或「IG:帳號」。
  5. 依分數十六進位字串由小到大排序，取前 N 名為得獎者（同分機率可忽略，若同分以比對鍵排序）。
  6. 遞補：得獎者若為同一人重複參加或放棄，依同一排序的下一順位遞補；頁面公開前 N+10 名完整排名，紀錄檔保存所有遞補原因。

驗證模式

下載的 JSON 紀錄內含完整標準名單、種子與得獎分數。任何人可：①確認名單雜湊與抽獎前公布的一致；②用下方 Python 程式（只需標準函式庫）重算，結果必須完全相同。

python3 verify.py list.txt "種子" FB 5

合併抽（FB＋IG）驗證：JSON／文字紀錄中的標準名單每行為「FB:帳號」或「IG:帳號」，已依 Unicode 碼位排序；名單雜湊 = SHA-256(以「\n」串接的前綴名單)；分數 = SHA-256(seed + "|ALL|" + 前綴項目)。同一帳號名稱在 FB 與 IG 各自計為一筆（只在同平台內去重）。可用以下任一方式重算：

python3 verify.py combined.txt "種子" ALL 10　（combined.txt 每行 FB:帳號 / IG:帳號；人工合併者為 FB:x+IG:y）
python3 verify.py fb.txt "種子" ALL 10 ig.txt　（兩份原始名單，程式自動加前綴；此方式不含人工合併）
