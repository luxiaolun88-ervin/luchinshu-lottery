    驗證模式：任何人都能重算

    • FB 參加者的比對鍵是 留言者的 from.id（粉專範圍的使用者 ID，不會因改名而變），畫面與紀錄同時顯示名稱；IG 比對鍵是 正規化後的 username（去 @、小寫）。
    • 標準名單 = 比對鍵依 Unicode 碼位排序、以「\n」串接；名單雜湊 = SHA-256(標準名單)。
    • 分數 = SHA-256(種子 + "|" + 平台 + "|" + 比對鍵)；依分數升冪排序取前 N 名。合併抽平台為 ALL，比對鍵為「FB:id」「IG:帳號」或人工合併的「FB:id+IG:帳號」。
    • 演算法與 index.html／verify.py 完全相同（共用 core.js）。下載的文字紀錄內含標準名單，可直接：python3 verify.py list.txt "種子" FB 5
    • 每位有效參加者只取「最早一則符合條件的留言」，紀錄包含留言 ID 與時間，可回貼文逐一核對。
